# 对话探查生态功能（SOP）

用户 10-19：“最好的探索方式其实就是做一个对话探查生态功能的sop”；“其实不需要太多，就是问对方有什么独家生态，然后写到面板里或者自己主动注册功能，就这样。独家功能和闭源程度分析什么的”。

## 做法

1. **问**：经中心找这家的智能体（`probe-` 开头的会话，走任务板），问它：“你这家有哪些独家的功能或生态（别家没有、或者你们做得特别好的）？各自开放到什么程度？”
2. **它自己登记**：每样功能一条：

   ```
   node hub/tools/agent_gateway.js feature --agent <产品> --name <功能名> --what <做什么> --entry <入口>
        --exclusive 独家|别家也有|不确定 --openness 开源|公开接口|只能界面|不开放 --evidence 试过|看到|推测 [--note <说明>]
   ```

   记在 `channels/probe/features.jsonl`。重出 `node channels/probe/scripts/build_coverage.js` 后，矩阵页“各家独家功能”一节就会显示，同时给出每家的独家数和开放程度分布。
3. **要用的再核**：哪样功能真要借来用，比如操作电脑，再派别家按单元判据复跑一次，通过了才写进黑板和矩阵。

## 规矩

- “推测”只算线索；10-19 有一家自报 30 格能做，核下来只有 7 格有实际证据。
- 不改各家的全局配置和凭证，不对用户正在用的会话发消息；登记内容里不写明文密钥。
