# @d_n3_1 [decision] #stage/research #kind/deliver #agent/n3
title: 调研材料来源不均衡时怎么处理
trigger: 审核员提交审核意见，指出部分调研样本量不足
alternatives:
  - 要求对应调研员补充材料
  - 接受现有材料进入辩论
  - 把问题标注出来一起交给专家辩论
choice: 把问题标注出来一起交给专家辩论
reason: 时间有限，专家辩论本身就能检验证据是否充分
impact: 辩论里出现对数据不全的质疑，但没有拖慢进度
action: deliver

# @d_n3_2 [decision] #stage/debate #kind/escalate #agent/n3
title: 辩论出现分歧时是否现在就收敛结论
trigger: 务实派和创新派在一次性迁移还是分批迁移上持续僵持
alternatives:
  - 现在收敛成一个折中方案
  - 保留两个方案都交给人工决策
  - 再给一轮时间让专家补充论据
choice: 保留两个方案都交给人工决策
reason: 两个方案的风险取舍属于业务判断，不该由综合者单方面拍板
impact: 决策呈报员要把两个方案都整理清楚，人工关的决策内容变多
action: escalate

# @d_n3_3 [decision] #stage/debate #kind/deliver #agent/n3

trigger: n16 指出社区调研样本没有对照现有系统约束
alternatives:
